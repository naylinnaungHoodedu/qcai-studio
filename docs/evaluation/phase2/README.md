## Abstention calibration (task 2.6)

Plan task 2.6: "Abstention floor plus margin calibrated on public-corpus items only, provisional until Phase 4". Plan Phase 2 H: "no threshold is final before the E1 freeze".

### Reproduce
```
python scripts/calibrate_abstention.py --check docs/evaluation/phase2/calibration_record_v1.json
python scripts/calibrate_abstention.py --write docs/evaluation/phase2/calibration_record_v1.json --update-package
```
- `--check` recomputes everything (ignoring `created_at` and `commit`). It also checks that the configuration package's floor, margin and `calibration_record_sha256` match the record.
- CI runs `--check` in the `api-and-evaluation` job.

### Inputs (public only)
Anything under `lqs/` is refused, and no learner record, tutor turn or rating is read.
- **The pre-registered BEP-1 fixture** (`apps/api/tests/data/phase2_calibration_queries.json`): BEP-1 fixture A with its strata and folds, plus hold-out B.
  - The fold rule is "sha256(query) first hex digit even -> cal, odd -> conf".
  - The four topic-free quiz stems are left out.
- **The AC-2-4/AC-2-5 fixture** (`apps/api/tests/data/score_floor_queries.json`). It equals the gated strata of the BEP-1 fixture plus hold-out B.
- **The 36 learner questions** of `MODULE_BLUEPRINTS`, each labelled with its own lesson.

### Configurations
- **`governed_as_configured`:** the committed manifest. Under D-31 nothing is approved, so the index holds authored spans only (41 entries).
- **`all_public_approved`:** a temporary manifest that approves every public-plane, bound item. The index holds 331 document spans; the 2026 video stays unbound (Q-10).

### Baseline (AC-2-5)
BEP-0 recorded no recall@5 baseline. CI checks out one commit, so the pre-migration commit is not available in the run. The baseline is therefore the frozen pre-migration search, `app.services.retrieval_legacy_p1`, run in the same run.
- Its fidelity is proven against a snapshot recorded from the unmodified code (`apps/api/tests/data/legacy_p1_baseline.json`).
- The legacy all-approved configuration serves all 24 assets, the 2026 video included, as the pre-migration code did.

### Selection rule (spec 3.14)
1. A floor is **feasible on the cal fold** when all of these hold:
   - no `oos_general` or `stop_only` cal query keeps a result;
   - cal in-domain recall@5 is at least the legacy recall;
   - learner-question recall@5 is at least the legacy recall.
2. For each configuration, take the contiguous feasible interval starting at the lowest feasible floor.
3. Intersect the intervals.
4. Floor = the midpoint of the intersection, rounded down to 0.05. Margin = the upper end minus the floor, rounded down to 0.05.
5. Confirm on the conf fold, hold-out B and the AC fixture.

Any failure, or an empty intersection, is a stop (plan Phase 2 L). The script then exits 3 and leaves the package unchanged.

### Why bm25f-v1 is not the default outside development
It is not strictly more conservative than the P1 floor:
- it answers more in-domain questions;
- it also returns results for more near-miss and course-word off-topic questions.

Under the D-05 freeze, `RETRIEVAL_GATE` therefore defaults to `p1-floor` outside development. Switching production is a D-05 remediation release that closes R-15, with this record attached.

### Limitations and fragility
These are recorded in the record's `limitations` and `fragility` lists.
- `coverage-v1` and the framing stopwords (`define`, `definition`, `term`, `terms`, `word`, `words`) were designed after looking at leaks on the whole repository fixture, the conf fold and hold-out B included. AC-2-4 on that fixture is therefore design-set evidence.
- `near_miss` and `oos_lexical` were not used in design, and they show the regression against P1 above.
- The learner questions appear verbatim in the authored spans, which makes them circular for the governed configuration.
- Learner-question recall has zero slack in both configurations. In the all-approved configuration the slot-equal metric is 27 against a legacy 28.
- There is no ULQS calibration split yet (Phase 4).

**No threshold here is final before the E1 freeze.**
