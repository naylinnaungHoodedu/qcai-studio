# Private evaluation corpus boundary

Licensed full text and verbatim evidence spans used for CS595 evaluation must remain in approved, access-controlled storage. They are not committed to this repository, copied into public container images, served by the source-asset API, or included in release bundles.

Use `../license-register.csv` to record the source, license, permitted use, and public-service decision for every corpus item. A library determination is required before a non-public item enters an evaluation run.
