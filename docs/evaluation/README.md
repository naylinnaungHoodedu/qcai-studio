# CS595 evaluation evidence

`evaluation/qcai_eval` implements the ULQS v1.0 validator and freeze check, evidence pointers, rater agreement, the seven
Table XV arms with their parity check, the E1-E4 runner with the four designs and their registered families (stub, recorded and refused live modes), payload logs, governance
records, contamination fingerprints, the seeded-fault fixtures and the statistics (Phase 10;
`docs/architecture/phase10-implementation-spec.md`). A passing check is not a completed experiment: RevB requires a frozen
120-200 item instrument, independent ratings, seven comparable arms and pre-registered tests, and no E1-E4 run has been
executed (DI-129..DI-148). The per-phase records are in `docs/evaluation/phaseN/`; Phase 10's are in
`docs/evaluation/phase10/` (synthetic records only).
